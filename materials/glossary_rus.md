# Словарь

**Агент** — программа, которая использует модель для выбора следующих действий и инструментов. Она должна уметь завершать работу, останавливаться по лимиту или запрашивать помощь.

**Аргументы** — значения, с которыми вызывают инструмент: например, идентификатор участника и название товара.

**Внедрение инструкций (prompt injection)** — приём, при котором в обычный на вид текст прячут указание агенту. Модель может ошибочно принять такое указание за поручение, хотя вложенный текст не получает прав системного сообщения.

**Инструмент (tool)** — именованная операция, доступная агенту: `get_coin_balance`, `create_order`. У инструмента есть имя, описание и список аргументов.

**Журнал (log)** — файл, в который записывается каждый вызов: время, инструмент, аргументы, ответ.

**JSON** — текстовый формат данных. Он поддерживает объекты, массивы, строки, числа, логические значения и `null`. Объект JSON превращается в словарь Python функцией `json.loads`; в этом проекте строка журнала содержит объект.

**JSONL** — файл, в каждой строке которого отдельная запись JSON.

**Код отказа** — короткое слово, которым сервер объясняет, почему не выполнил вызов: `OUT_OF_STOCK`, `USER_LIMIT_EXCEEDED`.

**Коины** — внутренняя валюта Лавки, за которую покупают мерч.

**MCP** — протокол, по которому программа узнаёт, какие инструменты предоставляет сервер, и вызывает их.

**Действие с последствиями** — операция, которая меняет состояние системы: списание коинов, отмена заказа, отметка о выдаче. Текст следующего сообщения сам по себе её не отменяет. Возможность исправить результат зависит от правил системы и прав пользователя; не каждое изменение технически необратимо.

**Системный промпт** — текст, который агент получает перед разговором: кто он, что делает, чего не делает.

**Словарь (dict)** — структура данных в Python: набор пар «ключ — значение», значение достаётся по ключу в квадратных скобках.

**Вариант** — один из нескольких наборов материалов расследования. Вариант назначает рандомайзер или стафф. Одна латинская буква `A`, `B`, `C`, `D` или `E` вписывается в `src/variant.txt`. Карточка помощника находится в `materials/helper_card_rus.md`.

**Хронология (timeline)** — восстановленный порядок событий с временными отметками. Основной результат разбора инцидента.
